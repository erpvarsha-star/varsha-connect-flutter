# Varsha Connect - Deployment Checklist

## Local Tooling Needed

Install on build machine:

- Flutter SDK
- Android Studio
- Java JDK compatible with Flutter/Android Gradle
- Firebase CLI
- Node.js
- Git

Current machine check:

- Node.js: installed
- Git: installed
- Flutter: not found
- Firebase CLI: not found

## Firebase Setup

Create Firebase project:

- Project name: Varsha Connect
- Enable Firestore
- Enable Firebase Auth
- Enable Cloud Messaging
- Enable Crashlytics
- Enable Analytics
- Add Android app

Recommended Android package:

`com.varshaforgings.varshaconnect`

## Firebase Auth

Phase 1 login options:

- Recommended: phone/PIN backed by custom claims
- Alternative: Firebase phone OTP plus app PIN

Custom claims needed:

- emp_code
- role
- department

## Firestore Deployment

Deploy:

- `firestore.rules`
- `firestore.indexes.json`

Commands after Firebase CLI is installed:

```powershell
firebase login
firebase use <project_id>
firebase deploy --only firestore
```

## App Environment Files

Flutter project will need:

- `android/app/google-services.json`
- Firebase options generated by FlutterFire CLI

Commands after Flutter/Firebase tools are installed:

```powershell
dart pub global activate flutterfire_cli
flutterfire configure
flutter pub get
```

- Cloud Function writes rows to Sheets using a Google service account.

## Deployment Readiness Gates

Gate 1 - Firebase ready:

- Firestore rules deployed
- Indexes deployed
- Auth enabled
- FCM enabled
- Service account ready for Sheets

Gate 2 - App ready:

- Login works
- Role claims load
- Dashboard loads role-specific data
- Attendance geofence works
- Forms submit
- Tasks update
- Notifications arrive with sound
- Scores save only from Manager/Plant Head

Gate 3 - Reporting ready:

- Attendance rows sync to Sheets
- Form rows sync to Sheets
- Task rows sync to Sheets
- Performance rows sync to Sheets
- Dashboard summary syncs
- Exceptions are visible

Gate 4 - Pilot ready:

- 10-15 pilot users loaded
- Phones verified
- Roles verified
- Shift assignments verified
- Managers know how to score
- Staff know how to submit daily forms

## Phase 1 Pilot Group

Recommended:

- 1 Plant Head
- 2 Managers
- 2 Supervisors
- 5-10 Shift Incharge / form filing users

Departments to include:

- Forge Shop
- Press Shop
- Heat Treatment
- Maintenance

These match Priority 1 forms.
